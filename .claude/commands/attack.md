devils-advocate 에이전트에게 현재 상태를 공격하게 한다. 집중할 영역: $ARGUMENTS

호출문에는 "약점을 찾아라"만 넣는다. 내가 이미 아는 약점이나 변명을 미리 알려주지 않는다.

결과가 오면:

1. 약점마다 직접 확인한다. 근거로 든 파일 위치를 열어 사실인지 본다. 사실이 아닌 공격은 이유를 적고 버린다.
2. 사실인 약점을 세 가지로 나눈다: 지금 고친다 / 발표에서 먼저 말한다(한계로 인정) / Q&A 답만 준비한다.
3. "지금 고친다"는 남은 시간 안에 되는 것만 고른다. 마감은 11/26 23:59다.
4. 영어 예상 질문은 `docs/qna.md`에 모으고 각 질문에 답 초안 2–3문장을 붙인다.

사용자에게는 약점 표와 내 추천 분류를 보여주고, 사용자가 정한 것을 `docs/decisions.md`에 남긴다.
