제출물을 검사한다. 고친 것이 있거나 제출 직전이면 이 명령을 돌린다.

1. `uv run python tools/check_submission.py`를 실행하고 출력을 그대로 보여준다.
2. `work/runs/`에 실행 결과가 있으면 가장 최근 두 개를 각각 `uv run python tools/score.py <파일>`로 채점한다. 두 실행 사이에 값이 달라진 케이스·키가 있으면 따로 표시한다. 다시 돌렸을 때 바뀌는 값은 채점에서도 바뀐다.
3. answer-auditor 에이전트로 정답을 독립적으로 다시 도출해 정답지와 대조한다.
4. 도구가 볼 수 없는 것은 사용자에게 확인 목록으로 묻는다:
   - 워크플로 이름 옆 설정 번호가 제출할 버전인가, 라이브러리 게시의 설정 버전과 같은가
   - 라이브러리 게시 창의 샘플 문서에 테스트 케이스 파일이 전부 체크됐는가
   - 승인 요청을 눌렀고 링크를 복사했는가
   - 설계서의 회색 안내 글씨를 지웠는가
   - 데모 영상이 3분 이내이고 문서 입력부터 결과까지 보이는가

결과는 세 묶음으로 보고한다: 제출을 막는 것 / 점수를 깎는 것 / 확인만 하면 되는 것. 오류가 0이 아니면 "제출 가능"이라고 말하지 않는다. 실행 결과 파일이 없어서 정확도를 확인하지 못했다면 그 사실을 맨 위에 적는다.
